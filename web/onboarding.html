Pi Jev Route · Getting started

Choose the right model
for your subagents.

Set up in three steps. Your main model stays unchanged. Restart Pi after changing environment variables.

01

Your model scope

Add the models you want to Pi’s settings.json enabledModels list. Only that list is eligible.

02

Your TypeSafe key

Set TYPESAFE_API_KEY or put the key in ~/.config/typesafe/api_key. The key is read locally, never shown here.

03

Descriptions & fallback

Add accurate model descriptions and choose a fallback. If no safe allowed fallback exists, Jev blocks dispatch rather than guessing.
