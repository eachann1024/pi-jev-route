# 技术参考

本文收录 npm 包的详细行为与运维说明。简要介绍见仓库中的 [README](../README.zh-CN.md)。

## 环境与安装

要求 Node.js 22.18+、Pi 0.85.1+。扩展使用 Pi 原生 TypeScript 加载器和 Node 内置模块，没有额外运行时依赖。若尚未安装 `pi-subagents`，先安装它，再安装本包并在 Pi 中执行 `/reload`：

```sh
pi install npm:pi-subagents@0.69.0
pi install npm:@each1024/pi-jev-route
```

路由默认开启。首次在本机交互式 Pi 会话中使用时会显示英文欢迎页，并启动本机页面服务以提供设置入口。执行 `/pi-jev-route-setting welcome` 可再次打开欢迎页；`/pi-jev-route-setting` 直接打开设置与审计页。仅安装 npm 包不会自动打开浏览器。

## 路由行为

主会话负责澄清需求、调研风险、完整定义有边界的工作、协调委派、做关键决策并总结。扩展处理符合条件的结构化原生 Pi 调用 `subagent({agent, task})`；省略单次调用的 `model` 参数即可启用选型。扩展依赖 `subagent({action:"list", capabilities:true})` 发现可用代理能力。

Jev 根据 `settings.json` 的 `enabledModels`、模型说明和路由规则选择模型。独立工作可以并行派发。普通工作通常优先选择已配置的轻量模型；样式任务在允许范围内使用当前主模型与 low 思考强度。不支持推理的模型使用 `off`。

每次调用或代理配置中的显式模型，仅当解析为允许的 `enabledModels` 项时保留。列表外模型（包括其他提供方模型及插件名 `pi-jev-route`）会被忽略，再由 Jev 从允许列表选择。扩展在执行前写入经过校验的 `provider/model:thinking` 覆盖。子代理启动、并行、工具、权限、预算和结果仍由原有子代理扩展负责。主会话模型与思考强度不会改变，路由也不增加权限。

## 首次欢迎页与本机页面

首次在本机交互式 Pi 会话中使用时，扩展显示英文欢迎页，其中有 **Open settings** 操作。执行 `/pi-jev-route-setting welcome` 可重新打开。欢迎流程会启动回环本机页面服务以提供欢迎页；仅安装 npm 包不会启动浏览器。`/pi-jev-route-setting` 打开设置和日志。

页面列出 `settings.json` 中 `enabledModels` 匹配到的模型，修改后自动保存。无论是否已有启用模型，都保留可搜索的全部模型下拉框；添加会把精确的模型编号追加到 Pi 的该列表。支持中文和 English 切换，之后的日志文字跟随所选语言。页面提供回退模型、样式策略和高级路由选项，没有备注栏。暂时不可用模型的说明会保留。分类过程中若设置发生变化，该次尝试会被阻止。并发设置编辑会因版本冲突而拒绝覆盖。

服务绑定 `127.0.0.1`，页面受令牌保护，并在闲置五分钟或会话切换后关闭。不会加载外部脚本、字体或资源。远程/无界面 Pi 需要本机交互会话才能打开页面；不会创建公网监听或隧道。

### 命令

```text
/pi-jev-route-setting          打开设置和日志
/pi-jev-route-setting welcome  重新打开欢迎页
/pi-jev-route-setting last     查看最新持久审计记录
/pi-jev-route-setting log <编号或唯一前缀>  查询一条无歧义记录
/pi-jev-route-setting status   查看启用状态与覆盖范围
/pi-jev-route-setting on       开启子代理路由
/pi-jev-route-setting off      关闭子代理路由，不改当前模型
```

## 覆盖范围与审计

**覆盖：**模型发起的结构化单个原生 Pi 子代理 `subagent` 调用（包括 `async:true`），且已先发现代理能力。

**不拦截：**工作流脚本/模板及其内部 `runs.run/all`、`/run`、定时任务、其他扩展直接 RPC/delegation、外部 CLI/job 执行器。嵌套路由取决于子代理是否加载本扩展，不作保证。模型发起但不支持的工作流/远程派发会记录为跳过并保持原参数；直接 `/run` 等绕过工具拦截的路径不会产生路由日志。本扩展不是全局启动策略拦截器。

公开的代理能力列表会缓存在当前会话。外部修改代理定义后应重新 list；会话内 create/update/delete 会让缓存失效。未知的原生/外部 runner 不会被猜测：扩展会阻止启动并提示先列出能力。此检查无法阻止受信任的代理配置在列出后发生变化。

终端审计标记显示简短原因、请求模型和审计编号，不代表任务已执行。兼容的结构化字段包含原因码、路由耗时、候选 ID、回退来源和有限规则快照。传输失败会分类记录，但不保存原始错误、响应正文、任务内容或凭证。`last` 和 `log` 查询 SQLite 持久记录；有歧义的前缀会被拒绝。

异步接受只记录为**已接受**，不代表完成。只有工具结果提供前台执行器配置时才会报告。不会后台轮询或虚构完成证据。返回的 async/run ID 不确认完成，也不确认实际模型。原始子代理结果保持不变，并追加模型可见回执，包含路由 ID、请求/报告模型、结果、执行证据状态和查询命令。只读工具 `jev_route_history` 可列出当前会话最近记录或按 ID 获取记录；显式设置 `allSessions` 才跨会话查询。它不保存任务或结果原文。`last` 显示跨会话最新持久记录；`log` 查询精确 ID 或唯一字面前缀。退出码 0 只证明执行器报告完成，不独立验证工作正确性。

## 隐私、凭证与失败处理

扩展直接调用 TypeSafe，复用现有凭证来源：

1. `TYPESAFE_API_KEY`
2. `~/.config/typesafe/api_key`

不需要 Gateway 账户或新凭证文件。Key 不会返回给 HTML 页面或写入日志。请保护 Key 文件（例如权限设为 `600`）。

分类会向 TypeSafe 发送子任务、代理名称、候选模型 ID/说明和路由规则；不会发送主会话、系统提示词、工具结果或思考。分类会单独计费。明显类似凭证的输入会跳过；这只是词法检查，不是完整的隐私/秘密扫描。过长任务或请求会跳过，不会静默截断。

普通主会话轮次、管理调用、列表内显式模型固定及已识别的外部 runner 不会触发分类。每次符合条件的派发最多请求一次，默认五秒超时且不重试。超时、缺少凭证、响应格式错误、敏感输入或低置信度时，依次回退到配置且允许的模型、允许的 `low` 别名、允许的主模型；没有安全回退则阻止派发。需要用户优先决策时也会阻止。低分类置信度不是代码任务成功概率。

设置和审计记录保存在 Pi agent 目录的 `jev-route.sqlite`，遵循 `PI_CODING_AGENT_DIR`，仅所有者可读写。日志只保存任务 hash，不保存任务原文或分类响应。不要在模型说明等用户编写的数据中填写凭证。日志不会自动删除。Node 22 的内置 SQLite 可能显示实验性警告。

## 任务监督设置

监督与路由设置存在同一条记录中。新配置及缺少 `supervision` 的旧配置默认开启观察、纠正和有限恢复的统一流程；已明确保存的关闭状态继续保留。旧版模式值在读取时规范化，不再提供三选一。关闭监督不停止任务，用户取消不会自动复活。监督判断调用 Jev 的 `jev-latest`，复查可能单独计费。纠正与恢复由原代理原模型执行，不切换模型。模型与思考配置仅为接管预留；接管执行接口尚不支持，所选配置暂不生效，页面禁用相关控件并保留已有值。

当前支持主会话纠正、当前会话所属异步子任务的观察与原模型恢复。恢复必须获得精确运行的退出证明；未知结果持久阻断重试。主会话自动恢复和换模型接管尚不支持，设置中的授权不能替代执行能力。三个真实 Pi 会话验收尚未完成，不能将注入测试等同于真实恢复成功。

页面沿用已有自动保存和 `If-Match` 冲突检查。每个监督选项说明机制：默认本地 5 秒轮询、空闲与深度思考阈值、复查间隔或新增工具证据、交接等待，以及恢复、接管、干预、自动干预时限、决策时间和检查次数上限。预计时间预算到时只提醒；自动干预时限到时停止后续自动干预并继续观察，不强制终止任务。用户与监督者等待暂停预算，子任务依赖等待继续计时。时间输入与默认占位使用秒或分钟。活跃工具、提供方思考和明确等待不算停滞。未知、外部、嵌套和未证明结束的前台工作显示为覆盖缺口；整个 Pi 进程崩溃不在覆盖范围内。

监督任务和事件使用与路由日志分开的表。目标、说明和证据有长度上限，证据中的类似凭证片段会被遮盖。每个会话最多保留 50 个任务。只有没有待执行动作及未确认动作意图的已结束任务会被清出空间；活跃或待执行任务已满时拒绝新增，不丢弃活动链。事件按会话保留最新 200 条。此保留策略不删除或改写路由日志。监督数值只由 policy parser 校验。预留接管思考默认值跟随该 parser；已存值缺失时页面显示 high。运行时快照提供 `supervision.tasks`、`supervision.events` 和 `supervision.coverage` 后，页面显示当前任务和审计时间线。扩展已从当前监督运行时提供该快照。

## 开发与迁移

本包取代早期提供主会话 `auto`/`shadow` 路由的本地实验。安装本包前，请从 Pi 扩展发现目录移除旧扩展，不要让两个版本同时占用 `/pi-jev-route`。本包不取代或修改独立审阅已完成回复的 Pi Jev Reply。

```sh
npm ci --ignore-scripts
npm run check
npm test
```

检查使用模拟分类与隔离临时存储，不消耗模型额度。`npm run check` 运行 TypeScript 检查且不生成文件。包内包含 Pi 原生扩展加载器所需的 TypeScript 源码及纯 HTML 页面。
